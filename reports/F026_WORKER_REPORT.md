It calls the unchanged `AiMerchantProposal.propose(Context,List<Quote>)`, then compares complete owner/task/mandate/quote snapshots after a selected model result and checks time again. Changes, read failures and expiry remove the selected quote while retaining model provenance. / 선택 후 최신 스냅샷을 비교하고 거절 시에도 실제 모델 사용 증거를 보존합니다.
