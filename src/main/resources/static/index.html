Floww · Hackathon demonstration

Bounded delegation, visible evidence.

Floww explores a purchase flow where an owner defines a budget and recipient, an AI proposes a merchant, and the server enforces the mandate before any testnet payment.

One service, three identities

Pharmacies A, B and C are deterministic merchant simulations served by one backend. They are not real pharmacies.

Durable task state

Tasks, decisions and chain-operation state are persisted in PostgreSQL. Requests do not rely on an always-running worker.

Public Sepolia evidence

The technical record separates live testnet transactions from simulated pharmacy fulfillment. It is not evidence of real-world delivery.
