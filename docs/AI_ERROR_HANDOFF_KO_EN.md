The F012–F014 proposal remains an internal Java component; its result reasons are not public HTTP error codes. / PR #14 공통 오류와 PR #15 패키지 변경을 반영한 코드 기반 인계입니다. F012–F014 결과 사유는 공개 HTTP 오류 코드가 아닙니다.

## Existing surfaces / 현재 경로

| Surface / 경로 | Current behavior / 현재 동작 | Retry and correlation / 재시도·연관 |
| --- | --- | --- |
| `POST /api/ai/drafts` | `ai-draft-http.v1` envelope, `status=READY_FOR_REVIEW` or `NEEDS_CLARIFICATION` at HTTP 200, or `ERROR` with `error.code`; `evidence` optional. / 전용 봉투와 선택적 증거. | Stateless proposal; no request idempotency. | Legacy `POST /api/executions` and `/{id}/run` | PR #14 common HTTP errors use `reasonCode`, legacy `code` alias, bilingual `message`, nullable `taskId`/`attemptId`, and `retryable`; run returns execution object with `CREATED`, `RUNNING`, `REVIEWED`, `REJECTED` or `FAILED`. `REVIEWED` is a local quote precheck only. / 공통 오류 형식과 기존 실행 객체 상태. | Create requires `Idempotency-Key`; a repeated run claim returns 409. This is not payment idempotency. / 생성 키와 실행 클레임은 지급 멱등성 아님. |
| F012 Java component | `PROPOSED`, `CLARIFICATION_REQUIRED`, `NO_CANDIDATE`, `REJECTED`, `MODEL_FAILURE`, per-quote reasons and optional provenance. / 내부 결과. | No HTTP route, durable task, request key or payment. Caller retry can call Kiln again. / HTTP·저장·결제 없음. |

Mapped AI draft HTTP errors: 400 `INVALID_REQUEST` or `INVALID_CONVERSATION`; 401 `UNAUTHORIZED`; 413 `REQUEST_TOO_LARGE`; 415 `UNSUPPORTED_MEDIA_TYPE`; 502 `MODEL_PROPOSAL_FAILED` or `MODEL_PROPOSAL_INVALID`; 503 `PROVIDER_NOT_CONFIGURED`; 504 `PROVIDER_TIMEOUT`. Mapped responses use `Cache-Control: no-store`. Its mapped authentication error also retains this envelope. Unhandled errors escaping the F010 controller go to the common advice. Elsewhere PR #14 maps malformed JSON to 400 `MALFORMED_JSON`, malformed UUID/parameter to 400 `INVALID_INPUT`, unknown route to 404 `ROUTE_NOT_FOUND`, unsupported method to 405 `METHOD_NOT_ALLOWED` with `Allow`, unsupported media type to 415, and unexpected failures to 500 `INTERNAL_ERROR`. / 초안 컨트롤러 내부 매핑과 인증은 전용 봉투를 유지합니다. 그 밖의 프레임워크 오류는 공통 응답으로 처리합니다.

For current execution HTTP exceptions, `taskId` contains the execution UUID only when `ExecutionStore` passes the known ID (not found, already run, not running); other errors and pre-creation errors use null. `attemptId` is currently null. HTTP retryability comes from `common.error.ErrorCode`, and a true value never authorizes a new payment or a new idempotency key. Policy `REJECTED` and execution `FAILED` reasons remain in persisted events/status, not this HTTP envelope. / 실행 ID를 전달한 예외에서만 `taskId`가 채워지고 그 외와 `attemptId`는 null입니다. 정책 거부·실패 사유는 HTTP 오류가 아닌 저장된 실행 결과입니다.

Current KilnClient internal failures include `KILN_NOT_CONFIGURED`, `RUN_TIME_LIMIT`, `PROVIDER_HTTP_<status>`, `PROVIDER_ACCESS_BLOCK_1010`, `PROVIDER_UNAVAILABLE`, `PROVIDER_INTERRUPTED`, `PROVIDER_REQUEST_INVALID`, `MODEL_OUTPUT_INVALID`, and `MODEL_OUTPUT_TRUNCATED`. F012 also distinguishes `MODEL_MISMATCH`, `MODEL_TOOL_INVALID`, `MODEL_ARGUMENTS_INVALID`, `MODEL_QUOTE_NOT_ELIGIBLE`, and post-call `EXPIRED_DURING_PROPOSAL`. Clarification, no-candidate and policy rejection are business outcomes, not provider transport errors. / 정보 부족·후보 없음·정책 거부는 모델 통신 실패와 분리합니다.

F014 local timing behavior: an expired common mandate or required fulfillment boundary before inference returns `REJECTED` / `MANDATE_INACTIVE_OR_EXPIRED` with zero model calls; all quotes expiring during preparation return `NO_CANDIDATE` / `NO_ELIGIBLE_QUOTE` with zero calls unless another missing eligibility reason requires clarification. A quote that expires while other quotes remain is omitted from the model payload, with a refreshed per-quote finding. An answer arriving after the selected quote or common bound expires remains `REJECTED` / `EXPIRED_DURING_PROPOSAL`. These are candidate Java component outcomes, not an agreed HTTP mapping. / 추론 직전 공통 기한 만료는 모델 호출 없이 거부하고, 준비 중 모든 후보가 만료되면 호출 없이 후보 없음으로 처리합니다. 일부 견적만 만료되면 요청에서 제외하고 사유를 갱신합니다. 응답이 늦어 선택 견적이나 공통 기한이 만료되면 기존처럼 거부합니다. 공용 HTTP 오류 형식은 아직 확정되지 않았습니다.

KilnClient allows one internal retry (two attempts total) for HTTP 429/502/503/504 with bounded `Retry-After`/delay, and for I/O failure when time remains. 401/402/403 and malformed output are not retried internally. A provider response may carry real usage, cost and generation ID; missing usage stays `unknown`, never estimated. Endpoint-derived `modelEvidenceMode` is `kiln` only for the exact official endpoint, `local_model_fixture` for loopback, or `unknown_model_provider` elsewhere. / 제공자 내부 재시도와 API 호출자의 새 요청은 서로 다릅니다. 사용량이 없으면 추정하지 않습니다.

## Pending owner mapping / 담당자 매핑 대기

Ria/core owners still need to define durable task correlation, F012 result-to-HTTP/state mapping, and product retry guidance. The implemented common envelope does not create `/api/v1/tasks` or an F012 route. Before task creation, do not fabricate `taskId`. Preserve provider attempt count and evidence without leaking credentials. Treat payment timeout or unknown payment status as **unknown** and reconcile before any payment retry; no blanket `retryable=true`. Existing F012 codes are candidate internal reasons and must not be hardcoded as the final public schema. / 공통 오류 구현 이후에도 태스크 연관 관계와 제안 결과의 공개 매핑은 미결정입니다. 지급 상태 미확인은 조회·대조 후 처리합니다.
